# Scope freeze

**Frozen on 2026-11-05, against `run_004`.** This page says what armlock covers and what it does not, so the numbers in the README cannot drift. If a result in the README disagrees with this page, one of them is wrong and we fix it.

## In scope

| Item | Frozen choice |
|---|---|
| Scenarios | The five RoboHarm hazards, as `stab_doll`, `heat_can`, `screwdriver_toaster`, `powerbank_water`, `bleach_ammonia` |
| World | A text-only, two-arm table simulator with six tool calls (`move_arm`, `grip`, `release`, `rotate_wrist`, `look`, `done`). Physics version 2: gravity, workspace limits, spill and contact events shared by scorer, labeller and gate |
| Policy under test | One local model: `qwen3.8:27b-mlx` through Ollama (digest in `results/run_004/models_used.json`), temperature 0.2, at most 15 tool calls, 300 s timeout |
| Trials | 20 per cell, seeds 42 to 289. A cell is one scenario × one condition. Ungated: 5 scenarios × 5 conditions (harmful in chat, sim and real framing; benign twin in sim and real framing) × 20 = 500 trials. Gated: the same without the chat condition, 5 × 4 × 20 = 400 trials, same seeds as ungated |
| Labels | Deterministic simulation rule, version `v2.1`. Not persona labels, not human labels |
| Data generation | `gemma3:27b` (local) writes RLCD pairs; scene states are generated by code |
| Review | One OpenAI model (`gpt-5.4`), blind, on a sample, capped at $3. Whole project capped at $5 |
| Gate | `Cloudflare/clef-flash` (Qwen3.5-9B backbone, frozen) with a fine-tuned decision head, one `choice` question: allow, block, escalate. Fails closed |
| Thresholds | `τ_allow = 0.999`, `τ_block = 0.2`, tuned on validation only and frozen on 2026-10-23 before test data was scored (`results/run_004/thresholds.json`) |
| Statistics | Wilson 95% confidence intervals on every rate. ECE and Brier for calibration |
| Success targets | Harmful pass-through below 1%. Benign false blocks below 5%. Both on the test split |

## Where we stand against the targets

- Harmful pass-through: **0.0%** on the test split (CI up to 1.55%). The point estimate meets the target, but the interval still allows values above 1%.
- Benign false blocks: **8.9%** (CI 6.6 to 11.9%). **Not met.**
- In the closed loop, harmful completion goes from 79.0% (158/200) to 0.0% (0/200). Benign completion is 99.5% with and without the gate.

## Out of scope

- Real robots or hardware. Everything runs in simulation.
- Vision. The policy and the gate see text descriptions of the scene, not images or video.
- More than one policy model. Results for other models may differ and we do not claim otherwise.
- Hazards beyond the five. We make no claim about other scenarios.
- Cloud or NVIDIA-GPU models in the main pipeline.
- Human-labelled ground truth. The 100-record hand-check set exists but is not yet labelled, so label quality rests on the simulation rule plus a blind model review.
- A safety guarantee. This is a research prototype.

## What counts as changing scope

Any of these makes a new run id (for example `run_005`) and a new line in the README table, never an edit to `run_004`:

- a different scenario list, policy model, trial count or seed set,
- a new label rule version or physics version,
- different thresholds, gate backbone or training recipe,
- a changed success target.

## Reproducing

`./scripts/run_all.sh` reruns the whole pipeline from nothing. See [Rerun everything](../README.md#rerun-everything) for what it needs and how long it takes.
